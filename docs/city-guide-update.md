# 查询与城市导航更新 · 2026-10-28

医院查询新增明确提交按钮及 Enter 查询，保留输入时筛选、城市／专业组合筛选、结果数量与无结果重置。导航和首屏主按钮直接定位查询表单。

新增中国地图及北京、天津标记，两者及下方城市入口均进入独立可刷新、可分享的城市列表（#city/beijing、#city/tianjin）。北京 5 家、天津 4 家；仅展示已发布、三甲等级附官方依据的医院，非全市完整名录或排名。等级依据与临床摘要分别核查，历史科室摘要不会因医院等级更新而被错误标为新资料。
